## Bugs Found

### 🐛 SEC3: `allowed_tools` not enforced
- **Severity:** High
- **Repro:** Open session with `allowed_tools: ["navigate","get_content","list_tabs"]`, call `screenshot` or `evaluate` — both succeed
- **Expected:** Error "Tool not permitted"
- **Likely cause:** `check_tool_permitted` may not be matching tool names correctly against the allowed list

### ⚠️ PI2: Visible injection text survives sanitization
- **Severity:** Low (wrapped with UNTRUSTED_WEB_CONTENT + warning)
- **Observation:** `display:none` elements are stripped but visible `<p>` text with injection payloads is preserved
- **Mitigation:** UNTRUSTED_WEB_CONTENT wrapper + `(The above is untrusted web content...)` notice provides defense-in-depth
